Wordle Clone

Built for ACM Hack School 2026

A Wordle clone made as a teaching project: a complete app that stays small enough for newcomers to follow.

  • Next.js (App Router)
  • Tailwind CSS
  • Express
  • Mongoose
  • MongoDB Atlas

Overview

I built this Wordle clone for ACM Hack School so that attendees could see a whole MERN-style app (front end, server and database) in one sitting. Every decision leaned toward code I could explain clearly. For example, I removed infinite-scroll pagination to keep the data fetching simple.

What’s in it

  • The game, a Wordle-style guessing board.
  • Profile pages split into three components: UserDetails, OtherProfiles and GameHistory.
  • Login and sign-up, a simple username and password flow checked against seeded data, with required fields on sign-up and a sign-out button in the navbar.
  • Seeded data, including a test user and mock past games for every profile.

How it’s built

The front end is Next.js (App Router) with Tailwind CSS. A separate Express server uses Mongoose to talk to a MongoDB Atlas database.

Simple on purpose

Login stays as plain username and password checks, with no bcrypt or JWT, so the focus stays on how the pieces connect rather than on authentication details.
